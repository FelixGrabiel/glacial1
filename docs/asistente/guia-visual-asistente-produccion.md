# Guía visual del Asistente de Producción

Archivo: `guia-visual-asistente-produccion.html` (se abre con doble clic en cualquier navegador; trae las capturas dentro y no necesita internet salvo para las letras).

Contenido: qué es y quién lo usa · qué debe existir antes de empezar · el turno en cinco pasos (contar, ver faltantes, solicitar, recibir, consumo y merma) · cada pestaña con captura · evidencias y lotes · problemas frecuentes · glosario.

Las capturas usan datos de ejemplo y se generaron con el módulo real. Si cambia una pantalla, hay que regenerarlas.
