# Cambios en la base de datos

El historial completo de cambios está dentro de cada proyecto de Supabase (Database → Migrations), con nombres
`glacial_20a…` (puente) en producción y `glacial_puente_0x…` + `glacial_20l…` en pruebas. Los dos proyectos tienen las
mismas funciones (se compara su huella después de cada cambio). Aquí se guardan, como referencia, los cambios hechos
a partir del 11-10-2026.
